# Chrome 密码管理器

版本 0.7.0。Manifest V3，本机使用 PBKDF2-SHA256（600,000 次）派生密钥，以 AES-GCM-256 加密密码库。可以只在本机使用，也可以连接本项目的导航站同步密文。

## 0.7.0 三站跟随浏览器外观与 Bilibili 提示隐藏

设置页独立的「网站外观」分区提供 Bilibili、淘宝（`taobao.com`）和闲鱼（`goofish.com`）三个深色模式选项，分别默认为「跟随浏览器」。随浏览器向网页提供的深浅色偏好切换，仅当前设备生效；这里使用网页可读取的 `prefers-color-scheme`，浏览器工具栏皮肤不一定会改变这个偏好。浏览器偏好变化时，已打开的支持页面会随之切换。

沿用 0.6.0 的 Bilibili 官方主题适配：使用网站已有的官方主题控制器或可识别的官方主题样式。具备上述官方主题能力的页面才会接管；暂不支持的页面保持原样。选择「不接管」会停止跟随，并恢复当前页面接管前的网站主题状态与偏好。

淘宝和闲鱼使用站点专用 CSS，在浏览器深色偏好下调整页面背景、文字、卡片与表单；浅色偏好或「不接管」会撤去扩展的深色样式。购物站适配仅限 `taobao.com`、`www.taobao.com`、`goofish.com`、`www.goofish.com` 的顶层网页，暂不接管 `login`、`item`、`pay` 等其他子站；Bilibili 外观适用于其域名及子域名的顶层网页。嵌入的第三方登录或支付框不接管。图片、视频和二维码保留原色，不使用整页反色滤镜。

「隐藏 Bilibili 广告拦截提示」默认开启，与 Bilibili 深色模式独立。它只通过 CSS 隐藏 B 站页面的 `.adblock-tips` 提示，动态出现的提示也会隐藏；关闭后立即恢复网站原有显示规则。

网站外观可在未创建、锁定或解锁密码库时设置，不依赖主密码、解锁密钥或后台会话。偏好以独立的 `websiteAppearance` 键保存在当前设备的 `chrome.storage.local`，不写入密码库、密码库行为设置、密文备份或服务器同步。设置页通过仅允许可信扩展页面调用的后台接口读取、按字段合并保存；独立队列避免多个设置页同时修改时覆盖其他选项，也不等待保险库恢复。其他已打开的设置页会即时更新，保存失败会恢复上次确认的选项。

读取失败时控件保持禁用，可点击「重新读取设置」。保存失败会显示具体的简短原因；若后台不支持新设置或扩展连接失效，页面会提示到扩展管理页重新加载扩展，再关闭并重新打开设置页。

## 0.5.0 永久关闭自动上锁

解锁后，在设置页开启「永久关闭自动上锁」。开关默认关闭，开启后不再因超时、系统闲置或锁屏自动锁定；浏览器重启或 MV3 后台重新启动后，也会自动恢复解锁。原来的自动锁定时间与闲置锁定设置会保留，关闭此开关后重新生效。

为支持重启恢复，扩展会在当前浏览器配置的 IndexedDB 中保存不可导出的 CryptoKey；不保存主密码，不上传恢复密钥，也不会把此设置或密钥同步到其他设备。开启后，能使用这份浏览器配置的人也能使用已解锁的密码库，因此只适用于你信任的个人设备。

「立即锁定」仍然有效：它会清除当前会话和恢复密钥，但保留「永久关闭自动上锁」偏好。手动锁定后，即使重新打开浏览器也需要先输入主密码；成功解锁后会按该偏好重新建立自动恢复。关闭开关会删除恢复密钥；「清空本机数据」会同时清除恢复密钥及所有本机设置。

更换主密码、导入密文备份或下载使用不同主密码的服务器保险库后，扩展会更新本机恢复密钥。恢复数据不可用或与当前保险库不匹配时，保持锁定并要求输入主密码。若浏览器恢复存储持续故障，可在解锁页点击「关闭常开模式」后按普通模式解锁；不会清除密码库。无法访问的密钥会先撤销恢复资格，并在下次后台启动时重试删除。

## 0.4.0 灵犀密码授权读取

导航站绑定灵犀账号后，可在灵犀设置中开启「允许读取密码」。默认关闭。解锁扩展，在设置页「灵犀密码读取授权」勾选授权并同步，后台才会收到独立的授权副本。授权范围为全部密码条目，不包含保险库主密码、派生密钥或扩展保存的导航站登录账号。

该副本在导航站使用 AES-256-GCM 加密存储，并按用户、用途和授权批次隔离。后台可以解密副本，供绑定的灵犀通过专用读取令牌调用；原 `/api/vault` 密文同步格式保持不变。授权同步要求 HTTPS（仅本机开发允许 localhost HTTP）。不要把授权副本的性质理解为原有端到端加密：开启此功能意味着信任导航站和绑定的灵犀服务能够读取密码。

已授权的当前设备在密文同步成功后自动更新副本。后台关闭读取或灵犀换绑、解绑时，立即清除副本并吊销令牌；重新打开必须在插件再次确认。任何设备更新原始密文而授权副本尚未更新时，服务拒绝读取旧副本，避免返回已经修改或删除的密码。扩展锁定不会撤销已经明确授权的服务器副本；可在导航站随时关闭。

导航站管理员需配置 `NAVIGATION_PUBLIC_URL=https://nav.example.com`。后台自动向灵犀注册固定 HTTPS 回调，专用令牌 23 小时有效，为服务器时钟偏差留出余量，并每 5 分钟检查、提前 1 小时刷新。审计只保存动作、条数与时间，不记录密码或用户名。

## 0.3.1 独立设备登录

扩展登录使用独立的 2 小时访问会话，不读取或写入网站的登录 Cookie。过期后使用保险库中加密保存的站点账号重新登录。同一服务器、同一账号重新连接时可替换扩展自己的会话；更改服务器或账号不会把旧令牌发送给新目标。

## 安装或更新

1. 打开 Chrome 的 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 `chrome_plug_in` 文件夹。使用 ZIP 时，先解压，再选择包含 `manifest.json` 的目录。
3. 把扩展固定到工具栏，打开「设置」，创建主密码。主密码忘记后无法找回。
4. 更新已安装的版本时保留同一路径，在扩展管理页点「重新加载」，然后刷新需要填充的网页。建议更新前导出密文备份；不要通过卸载来更新，以免删除本机数据。

服务器同步需要支持本项目保险库接口的主站后端。0.5.0 的自动上锁设置和 0.6.0–0.7.0 的网站外观设置完全在插件本机生效，不需要为此升级主站后端，也没有改变保险库 v1 文件格式。

## 0.3.0 界面、语言与介绍

弹窗重新整理了网站匹配、账号列表、详情与编辑布局；设置页增加分区导航，并适配深浅色主题和窄屏。页面内的账号提示也使用统一样式。

支持简体中文、繁体中文、English 和日本語。默认「跟随浏览器」，未支持的浏览器语言回退英语。可在弹窗或设置页的「界面语言」中手动选择；选择会保存在当前浏览器，并即时更新其他已打开的扩展页面和网页账号提示，不修改账号标题、备注或正在编辑的内容。Chrome 扩展管理页中的名称与描述跟随浏览器语言。

首次打开会显示使用介绍，说明本机加密、网站填充和可选同步。关闭或点击「开始使用」后会记住状态；以后可通过弹窗右上角的问号或设置页「使用介绍」重新查看。清空本机数据也会重置介绍和语言偏好。

## 日常使用

- 添加账号时自动带入当前网站标题与地址；可编辑标题、用户名、密码及备注。
- 当前网站的匹配账号排在前面，可勾选「仅当前网站」或搜索全部条目。
- 默认按精确主机名匹配。需要共享子域账号时，显式保存 `*.example.com`；该写法匹配子域，不包含根域 `example.com`。
- 详情中的密码默认隐藏，点「显示」后 10 秒自动隐藏。复制密码不会显示明文；剪贴板不会承诺自动清空。
- 密码生成长度可设为 8–64 位，可选择是否包含符号。
- 登录表单旁的提示支持动态加载页面、SPA 切换和多个表单；点击后只填写所选表单，不自动提交。
- 弹窗的「填充当前页」针对主框架；嵌入框架里的表单使用框架内自己的账号提示。浏览器设置页、商店等受限页面不能注入；刚装完扩展需刷新网页。
- 可关闭网页提示、调整自动锁定时间、设置系统闲置锁定和自动上传，也可在当前浏览器永久关闭自动上锁。
- 「网站外观」可让 Bilibili、淘宝和闲鱼的顶层网页跟随浏览器深浅色偏好，并独立控制 Bilibili 广告拦截提示。每站可单独选择「不接管」，与密码库锁定状态无关。

锁定会清除扩展后台会话与扩展界面的明文状态；已经填写到网页、复制到剪贴板或导出的内容不受锁定影响。默认只在内存保存密钥，因此 MV3 后台被浏览器回收或浏览器重启时也会锁定；显式开启「永久关闭自动上锁」后，才会使用上述本机恢复机制。

## 连接和跨设备恢复

服务器地址填写你自己部署的导航站，例如 `https://nav.example.com` 或 `http://192.168.1.10:9200`，使用导航站账号登录。没有预填的外部服务器，不会主动连开发者的服务器。

服务器表单会在当前浏览器记住地址与账号，刷新或再次打开设置时可继续填写。草稿仅包含这两项；站点密码不进入表单缓存，只在绑定成功后写入加密密码库。

解锁后，若地址规范化结果和账号都与已有绑定一致，密码框会提示「已加密保存，留空可沿用」；点击「连接 / 更新账号」时可复用加密库中的密码。改地址、改账号或首次绑定都需要输入站点密码。重新连接仍会检查远端版本，不会因为复用密码而跳过冲突选择。解绑会清除连接表单草稿，清空本机数据也会清除草稿。

- 远端为空：连接后上传首份密文。
- 远端已有密码库：连接后暂停上传，提示选择保留哪一份，避免新设备的空库覆盖服务器。
- 新设备恢复：创建本机库后连接服务器，填写「服务器密码库的主密码」，点击「下载并替换本机」。恢复后用远端密码库的主密码解锁。
- 双方都有修改：普通上传返回冲突。先备份本机密文，再选择下载远端，或明确「用本机覆盖服务器」。覆盖仍有版本校验，期间又发生修改会再次提示冲突。
- 自动上传失败会保留待上传标记并显示错误。修复网络或账号后可手动上传；重新解锁会继续尝试符合设置的待上传修改。
- 更换主密码后同步新的密文，其他设备恢复时使用新主密码。
- 解绑只停用本机绑定，不会删除服务器密文。

原保险库同步全程使用应用层密文；单独授权灵犀读取的副本通过 HTTPS 发送到后台并重新加密存储。服务器账号密码只发往用户配置的登录接口。公网必须 HTTPS。内网 HTTP 没有传输加密，登录凭据可能被同网段观察到。

## 备份与导入

密文导出可在锁定状态进行，也可在尚未创建密码库的新设备上导入。导入密文先验证原主密码，再替换本机；失败不会覆盖已有数据。成功后停止自动同步，需重新绑定服务器。

明文 JSON 导入会追加条目并分配新 ID；导入整个文件前会验证每个条目。明文导出需确认，并只包含条目，不包含服务器登录凭据。当前不支持 Chrome CSV、TOTP、Passkey 或团队共享。

单份密文上限 1 MB，导入文件上限 4 MB。可以按需导出备份，不要把真实导出文件放进扩展目录。

## 开发与验证

在项目根目录运行：

```sh
pnpm test
pnpm test:extension
pnpm typecheck
pnpm build
pnpm pack:extension
```

`pnpm test:extension` 运行扩展与服务器密文接口的回归，包括语言选择、翻译 key 和占位符完整性、跨页面更新、服务器表单草稿、凭据复用、三站外观切换、Bilibili 提示隐藏，以及外观设置的消息权限、并发合并和保险库隔离。只检查语言模块时可运行 `node --test tests/extension-i18n.test.mjs`。

打包生成 `chrome_plug_in-0.7.0.zip`，ZIP 根目录直接包含清单与运行文件，包括 `_locales` 和界面翻译；不含开发工具和文档。安装说明与设计说明保留在源目录。

可选真实浏览器回归：需要 Playwright 或 playwright-core 以及可运行的 Chromium/Chrome。脚本只创建 `.tmp` 下的临时浏览器配置和本地模拟服务器，不使用真实账号或现有浏览器配置。例如 PowerShell：

```powershell
# 使用已安装的 Playwright 模块入口；省略则从项目依赖解析 playwright
$env:PLAYWRIGHT_MODULE = 'C:/path/to/playwright-core/index.mjs'
# 使用系统 Chrome；省略则使用 Playwright Chromium
$env:TEST_BROWSER_CHANNEL = 'chrome'
pnpm test:browser
```

系统 Chrome 使用 CDP 在独立测试配置内加载扩展。脚本覆盖首次介绍及重新打开、四语跨页面切换、表单草稿恢复、首次向导、新增与搜索、密码遮罩、真实 content script 填充、绑定冲突、不同主密码跨设备恢复、留空密码重连、上传和锁定清理。

外观的本地网页夹具复用生产 CSS 和脚本，用于检查样式、主题切换与媒体保色；这种验证不代表已在真实淘宝、闲鱼网站安装扩展完成实测。
