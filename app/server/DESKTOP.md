# 自由桌面

入口为 `/desktop`；普通导航保留在 `/navigation`。设置 → 外观 → 首页模式可将自由桌面设为默认首页。桌面使用现有壁纸与当前设备的深浅色偏好，独立于原有的“桌面”外观预设。

- 顶部菜单栏、底部 Dock，时钟、搜索、天气、每日一句、工作台为独立组件。
- 开启“编辑桌面”后，可拖动图标、文件夹或组件把手。支持鼠标/触摸和键盘：聚焦把手，空格开始/结束，方向键移动，Esc 取消。
- 采用吸附网格保留空位；目标被占用时取消移动并保留原位，不自动避让或重排其他组件，也不提供自动排列入口。电脑与窄屏分别保存布局，不改变文件夹原始尺寸；超出屏幕的文件夹使用适配预览，窗口展示全部图标。
- 文件夹窗口不遮挡整个桌面，图标可拖出窗口，也可拖入桌面上的其他文件夹。窗口内提供“移到桌面”按钮作为触摸和键盘操作的替代入口。
- 新模式不显示分组。桌面选项中的“按原分组收纳为文件夹”将原分组散落图标收进同名文件夹，保留已有文件夹；重复运行不重复创建。原分类保留供导航模式使用。
- 普通导航模式也支持文件夹排序与跨分组拖动，文件夹成员随之移动。
- 普通导航的编辑工具栏、手机更多菜单和桌面编辑区可批量删除图标，支持搜索、筛选和核对清单。设置 → 书签与图标可清空全部图标，需输入确认文字；保留文件夹、分组和其他配置。

## 存储与接口

使用现有 settings 表中的 `desktop_layout`，格式为 `{version:1,wide:{},compact:{}}`，项目键仅允许 `site:<id>`、`folder:<id>` 和五种 `widget:<name>`。坐标按列/行保存，宽屏 12 列，窄屏 4 列。布局无数据库迁移；JSON 备份恢复会重映射站点与文件夹 ID。

- `GET /api/desktop/layout`：读取并清理过期项目位置。
- `PATCH /api/desktop/layout`：`{viewport,placements:[{id,col,row}]}` 增量写入；`{viewport,reset:true}` 重置当前屏幕布局。
- `POST /api/desktop/move`：`{site_id,folder_id,viewport,position?}`；移回桌面时必须提供位置。文件夹归属、排序和坐标在一个事务中写入。
- `POST /api/desktop/collect-groups`：收纳现有分组中的散落图标。
- `PATCH /api/folders/reorder`：`{items:[{id,category_id}]}`；先完整校验再原子更新文件夹和成员。
- `POST /api/sites/bulk-delete`：`{ids:[id,...]}` 删除选中图标；或 `{all:true,confirm:"delete-all-sites",expected_ids:[id,...]}` 删除所有图标。两种范围互斥，空选择、重复或失效 ID 拒绝处理；全部删除时当前 ID 集合与确认清单不同则返回 409，要求刷新清单重确认。图标删除和桌面位置清理在同一事务内完成。

所有管理接口要求登录，布局请求限制 64 KiB。匿名桌面仅能读取公开 bootstrap 数据，不能调整布局。
